# Record Label Landing Page

A single-page landing site for the label. Plain HTML/CSS/JS — no build step.

## Edit content
All text, artists, releases, and social links live in `content.js`.

## Artist photos
Drop photos into `images/artists/` and make sure each file name matches the
artist's `image` path in `content.js` (e.g. `images/artists/miraculum.jpg`).
If a photo is missing, the site shows the artist's initials instead.

## Preview
Open `index.html` in Chrome.

## Publish on GitHub Pages
1. Push this folder to a new GitHub repo.
2. Repo **Settings → Pages** → Source: `main` branch, `/ (root)`.
